# PRD - 소닉 애니메이션 뷰어

## 1. 개요

`sonic-sprite.png` 스프라이트 시트에 들어있는 소닉의 모든 동작을 차례대로 재생해 보여주는 pico2d 프로그램. 동작마다 어울리는 속도로 화면을 이동한다.

| 항목 | 내용 |
|---|---|
| 소스 | `Labs/LEC09/sonic_animation_viewer.py` (단일 파일) |
| 리소스 | `Labs/LEC09/sonic-sprite.png` |
| 라이브러리 | pico2d |
| 실행 | `Labs/LEC09` 폴더에서 `python sonic_animation_viewer.py` |

## 2. 요구사항

| ID | 요구사항 | 구현 기준 |
|---|---|---|
| R1 | 시트의 모든 동작을 재생 | 시트의 한 줄 = 한 동작, 4절의 10개 동작(프레임 76개)을 전부 재생 |
| R2 | 한 동작을 5번 반복 | `LOOP_COUNT = 5` |
| R3 | 동작 사이에 1초 쉼 | `PAUSE_TIME = 1.0`, 마지막 프레임을 그 자리에 유지한 채 정지 |
| R4 | 끝나면 처음부터 무한 반복 | 10번째 동작 후 1번째 동작으로 복귀 |
| R5 | 충분히 확대해서 표시 | 1200x800 캔버스에 8배 확대 (`SCALE = 8`) |
| R6 | 단계별 개발, 커밋 20개 이상 | 7절 참고 (소스 커밋 36개) |
| R7 | 종료 (PRE-PRD에는 없으나 필요) | ESC 또는 창 닫기, 정지 시간 중에도 즉시 반응 |
| R8 | 동작에 어울리는 이동 (추가 요구) | 동작별 `speed`로 오른쪽으로 이동, 제자리 동작은 화면 중앙에 고정 |

## 3. 스프라이트 시트 분석

- 크기 399 x 525, **배경은 이미 투명**(알파 0) → 컬러키 처리 없이 `load_image()`로 바로 사용
- 소닉 프레임은 10개 줄에 총 76개이고, **한 줄이 한 동작**이다.
- 프레임 크기가 20~40 x 26~45px로 제각각이고 간격도 일정하지 않아 **격자 분할 불가 → 프레임별 좌표를 표로 관리**
- 맨 위 제목 글자, 맨 아래 크레딧 글자, 그 옆 다른 캐릭터 2개(노란색/갈색, 각 1프레임)는 애니메이션이 아니므로 제외

## 5. 화면, 그리기, 이동 규칙

| 상수 | 값 | 의미 |
|---|---|---|
| `CANVAS_W, CANVAS_H` | 1200, 800 | 캔버스 크기 |
| `SCALE` | 8 | 확대 배율 (가장 큰 프레임 45px → 360px, 화면 높이의 45%) |
| `GROUND_Y` | 120 | 발이 닿는 바닥선의 화면 y좌표 |
| `LOOP_COUNT` | 5 | 동작별 반복 횟수 |
| `PAUSE_TIME` | 1.0 | 동작 사이 정지 시간(초) |
| `START_X` | 160 | 이동하는 동작이 출발하는 화면 x좌표 |
| `EDGE` | 160 | 화면 밖으로 완전히 나갔다고 보는 여유 폭 (가장 넓은 프레임의 절반) |
| `TICK` | 0.01 | 화면을 다시 그리는 간격(초) |

### 그리기

- **가로**: 캐릭터 위치 `x`에 프레임 중앙을 맞춘다.
- **세로**: 동작마다 프레임들의 가장 낮은 `bottom`을 기준선(`base`)으로 삼아 바닥선에 맞추고, 각 프레임은 시트에서 기준선보다 떠 있는 만큼(`b - base`) 그대로 띄운다. 걷기에서 발이 살짝 들리는 것 같은 시트의 높이 차이가 유지된다.
- 그리기 호출: `sheet.clip_draw_to_origin(l, b, w, h, x - w*SCALE//2, GROUND_Y + (b - base)*SCALE, w*SCALE, h*SCALE)`

### 이동

- `speed`가 0인 동작(idle, turn, pose)은 화면 중앙(`CANVAS_W // 2`)에서 제자리 재생한다.
- `speed`가 0보다 큰 동작은 `START_X`에서 출발해 초당 `speed` px씩 오른쪽으로 이동한다. 시트의 소닉이 오른쪽을 보고 있어 방향은 오른쪽 하나다.
- 화면 오른쪽으로 완전히 나가면(`x > CANVAS_W + EDGE`) 왼쪽 밖(`-EDGE`)에서 다시 들어온다.
- 동작이 바뀔 때마다 위치를 출발점으로 되돌린다.
- speed 값은 걷기 < 달리기 < 질주 순으로 빨라지게 하되, **5회 반복이 끝났을 때 캐릭터가 화면 안에 멈추도록** 맞춘 값이다. delay나 캔버스 폭을 바꾸면 멈추는 위치가 달라지므로 speed도 다시 확인해야 한다.

### 시간

- 프레임은 **경과 시간**으로 고른다: `index = int((지금 - 시작) / delay)`, `index`가 `프레임 수 * LOOP_COUNT`에 도달하면 끝.
- 위치는 `TICK`마다 `speed * 지난 시간`만큼 옮겨 부드럽게 이동시킨다.
- 이렇게 하면 그리는 데 걸리는 시간과 상관없이 동작의 길이와 이동 거리가 일정하다.

## 6. 코드 구조

```python
# 상수 (5절)
# ANIMATIONS = [{'name': 'idle', 'delay': 0.15, 'speed': 0, 'frames': [...]}, ...]   (4절)

def handle_events():             # SDL_QUIT, ESC → running = False
def draw_frame(frame, x, base):  # clear → 5절 규칙으로 확대 출력 → update
def wait(seconds):               # 0.05초씩 끊어 쉬면서 handle_events 호출
def play(anim):                  # 시간 기반 루프로 5회 재생하며 이동 → wait(PAUSE_TIME)

open_canvas(CANVAS_W, CANVAS_H)
sheet = load_image('sonic-sprite.png')
running = True
while running:                   # R4 무한 반복
    for anim in ANIMATIONS:
        if not running: break
        play(anim)
close_canvas()
```

`play()`의 루프:

```python
x = START_X if anim['speed'] > 0 else CANVAS_W // 2
start = prev = get_time()
while running:
    handle_events()
    now = get_time()
    index = int((now - start) / anim['delay'])
    if index >= len(frames) * LOOP_COUNT:
        break
    x += anim['speed'] * (now - prev)
    prev = now
    if x > CANVAS_W + EDGE:
        x -= CANVAS_W + EDGE * 2
    draw_frame(frames[index % len(frames)], int(x), base)
    delay(TICK)
wait(PAUSE_TIME)
```

- 전역 변수는 `running`, `sheet` 두 개만 사용한다.

## 7. 개발 단계와 커밋

규칙: 커밋 메시지는 한글로 쓴다. 한 커밋에는 한 가지 변경만 담고, 모든 커밋은 실행 가능한 상태여야 한다. 브랜치는 `lec09-animation-viewer`이며 아래 번호는 소스 커밋만 센다.

| 단계 | # | 커밋 내용 |
|---|---|---|
| 1. 뼈대 | 1 | 캔버스를 열고 닫는 최소 프로그램 |

| | 3 | 스프라이트 시트 로드 및 원본 출력 |
| 2. 프레임 한 개 출력 | 4 | 화면 상수 정의 |
| | 5 | idle 첫 프레임을 잘라 8배로 확대 출력 |
| | 6 | `draw_frame()` 분리, 중앙/바닥 정렬 |
| 3. 동작 한 개 재생 | 7 | idle 프레임 좌표 추가, 순환 재생 |
| | 8 | `ANIMATIONS` 구조와 `play()` 도입 |
| 4. 재생 규칙 | 9 | 5회 반복 |

## 8. 완료 기준

- [ ] 10개 동작(시트의 10개 줄)이 표의 순서대로 모두 재생된다.
- [ ] 각 동작이 정확히 5회 반복된 뒤 1초 멈춘다.
- [ ] pose 다음에 idle로 돌아가 계속 반복된다.
- [ ] walk, run, spin, ball, dash, peel_out, push는 오른쪽으로 이동하고, idle, turn, pose는 화면 중앙에 머문다.
- [ ] 이동하는 동작이 화면 밖으로 나가면 반대편에서 다시 나타나고, 1초 정지 때 캐릭터가 화면 안에 보인다.
- [ ] 옆 프레임 조각이 섞여 보이지 않고, 발이 미끄러지는 느낌이 심하지 않다.
- [ ] 재생 중이든 정지 중이든 ESC / 창 닫기로 바로 종료된다.
- [ ] 소스는 `sonic_animation_viewer.py` 한 파일이고, 커밋이 20개 이상이다.
